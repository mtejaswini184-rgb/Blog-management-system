# The Nexus - Blog Management System

A simple full-stack blog management system built during my Full Stack Development Internship at Codomax Digital Solutions.

## 🚀 Live Demo
[View Live Site](https://mtejaswini184-rgb.github.io/Blog-management-system/)

## 📋 Features
- Create, view, edit, and delete blog posts
- Form validation (title/content length checks)
- REST API built with Express.js
- Responsive design with mobile support
- Smooth animations and hover effects
- Comic-style "POW!" click effects

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript (Fetch API)
- **Backend:** Node.js, Express.js
- **Tools:** Git, GitHub, Postman, VS Code
